# C35 Teknik Kararlar

- Canonical millisecond UTC ISO boundary seçildi.
- Calendar date, instant ve duration ayrıldı.
- Date mutable olduğu için clone/snapshot açıklandı.
- Now dependency olarak enjekte edildi.
- Temporal API derinliği kapsam dışı bırakıldı.
