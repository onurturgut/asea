# C34 Kaynak Notları

ECMA-262 Number bölümündeki finite, integer, safe integer, EPSILON ve MAX_SAFE_INTEGER
davranışları; Math bölümündeki rounding fonksiyonları doğrulandı. EPSILON yalnız 1
civarındaki representable farkın ölçeğidir. Math.random algoritması implementation
defined'dır ve cryptographic guarantee sağlamaz.

Kaynak: [Numbers and Dates](https://tc39.es/ecma262/multipage/numbers-and-dates.html).
