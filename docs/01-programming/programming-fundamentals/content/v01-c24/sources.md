# Kaynaklar

- [NIST SP 800-142](https://csrc.nist.gov/csrc/media/Projects/automated-combinatorial-testing-for-software/documents/SP800-142-101006.pdf): error, fault ve failure ayrımını kurmak için temel terminoloji.
- [MDN — Control flow and error handling](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Control_flow_and_error_handling): JavaScript exception akışı ve Error nesneleri.
- [MDN — try...catch](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/try...catch): `try`, `catch`, `finally` kontrol akışı.
- [MDN — throw](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/throw): exception'ın çağrı zincirinde ilerlemesi ve Error nesnesi kullanımı.
- [MDN — Error cause](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Error/cause): yeniden fırlatmada orijinal neden bağlamını koruma.

Kaynaklar teknik doğrulama içindir. Öğrenci anlatımı ASEA'nın ihtiyaç → sezgi →
örnek → teknik adlandırma standardına göre yeniden oluşturulmuştur.
