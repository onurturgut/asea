# Bilgi Kartları

- **Symptom:** Dışarıdan gözlenen sorun işareti.
- **Defect/fault:** Kod veya tasarımdaki kusur.
- **Error state:** Program iç durumunun beklenenden sapması.
- **Failure:** Gözlenen davranışın sözleşmeden sapması.
- **Exception:** Normal akışı kesip çağrı zincirinde ilerleyen olay.
- **Syntax failure:** Kodun çalışmadan önce ayrıştırılamaması.
- **Runtime failure:** Geçerli kod yürürken işlemin tamamlanamaması.
- **Logic failure:** Programın durmadan yanlış sonuç üretmesi.
- **Contract failure:** İlan edilen girdi, çıktı veya durum kuralının ihlali.
- **Environmental failure:** Gerekli dış koşulun sağlanmaması.
- **Error boundary:** Failure'ın ele alındığı sorumluluk sınırı.
- **Recovery:** Güvenli ve tanımlı duruma dönüş davranışı.
