# Proje Artımı — V01-CP01 Güvenilir Problem Çözücü

Capstone hazırlığına ilk failure contract katmanını ekleyin:

- En az iki dış girdi doğrulansın.
- Başarı ve başarısızlık sonuçları ayırt edilsin.
- Kararlı hata kodu ile kullanıcı mesajı ayrı olsun.
- Invalid input hiçbir yan etki üretmesin.
- Normal, boundary ve invalid kanıt tablosu saklansın.

Bu kayıt C25'te minimal failing case ve hipotez günlüğüne başlangıç olacaktır.
