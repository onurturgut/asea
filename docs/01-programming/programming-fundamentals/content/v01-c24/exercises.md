# Alıştırmalar

## 1. Kanıtla sınıflandır

Beş olayı syntax, runtime, logic, contract veya environmental olarak sınıflandırın:

1. Eksik parantez yüzünden dosya başlamıyor.
2. Doğru girdi için yüzde yanlış hesaplanıyor.
3. Zorunlu yapılandırma alanı yok.
4. `null.name` okunmaya çalışılıyor.
5. `-3` ilerleme değeri kaydediliyor.

Her cevapta bir kanıt yazın.

## 2. Error contract yaz

`durationMinutes` için 10–180 tamsayı sınırında başarı biçimi, iki hata kodu,
kullanıcı mesajları ve recovery kararları tasarlayın.

## 3. Yayılma yolunu çiz

`form → validate → save → render` hattında validation failure'ın nerede
oluştuğunu, nereden geçtiğini ve nerede kullanıcı mesajına çevrildiğini gösterin.
