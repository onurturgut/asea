# Chapter Özeti

C24, “hata”yı tek bir etiket olmaktan çıkardı. Symptom, defect, error state,
failure ve exception'ın olay zincirindeki farklı rollerini; syntax, runtime,
logic, contract ve environmental sınıflarını kanıtla ayırdınız. Input boundary
için başarı biçimi, error code, user message, diagnostic bağlam, recovery ve
safe state içeren bir sözleşme tasarladınız. Bu kanıt C25'in sistematik debugging
sürecine devredildi.
