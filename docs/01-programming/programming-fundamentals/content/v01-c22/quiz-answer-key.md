# Quiz Açıklamalı Cevap Anahtarı

1. Hangi değerin önce geleceğini tanımlar.
2. Kalan bölümün en küçüğünü doğru `start` konumuna yerleştirir.
3. Swap için değerin bulunduğu konum gerekir.
4. İlk eleman tek başına sıralı önektir.
5. Kaydırmalar eski konumunun üzerine yazabilir.
6. Eşit anahtarlı kayıtların özgün göreli sırasını.
7. Eşit kayıtlar kaydırılarak stability bozulabilir.
8. Hayır; biri ek alan, diğeri çağıranın verisini değiştirme kararıdır.
9. Mutasyona uğratır ve aynı referansı döndürür.
10. Değerler string sırasıyla karşılaştırılabilir.
