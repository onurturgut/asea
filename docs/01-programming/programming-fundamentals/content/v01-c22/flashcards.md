# Bilgi Kartları

- **Sorting:** Comparator’a göre düzenleme.
- **Selection sort:** Kalan bölümün en küçüğünü seçme.
- **Insertion sort:** Yeni değeri sıralı öneke yerleştirme.
- **Swap:** İki konumdaki değeri karşılıklı değiştirme.
- **Shift:** Değeri komşu konuma kaydırma.
- **Sorted prefix:** Doğru sıralandığı kanıtlanan başlangıç bölgesi.
- **Stability:** Eşit anahtarlı kayıtların göreli sırasını koruma.
- **In-place:** Girdiyle büyüyen ikinci koleksiyon kullanmama.
- **Comparator:** Sıralama ilişkisini belirleyen fonksiyon.
