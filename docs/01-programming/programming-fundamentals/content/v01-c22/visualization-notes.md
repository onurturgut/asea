# Görselleştirme Notları

1. Selection görünümünde sıralı önek ve taranan aday bölgesi.
2. `smallestIndex` kartında değer ve index’in birlikte gösterimi.
3. Insertion görünümünde `currentValue`nun el üzerinde tutulması.
4. Sağa kayan değerler ve açılan boşluk.
5. Eşit puanlı kimlikli kartlarla stability karşı örneği.
6. Hareket azaltma tercihinde animasyon yerine ileri/geri state tablosu.

Renkler etiket ve konum göstergeleriyle desteklenmelidir.
