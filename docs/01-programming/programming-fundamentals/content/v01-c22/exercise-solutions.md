# Alıştırma Çözümleri

1. `[1,2,4,5]`, `[1,2,4,5]`, `[1,2,4,5]`; her tur tamamlanan öneki büyütür.
2. `[2,5,4,1]`, `[2,4,5,1]`, `[1,2,4,5]`.
3. Sırasıyla `[]` ve aynı tek değerli array; dış döngüler çalışmaz.
4. Değer sırası doğru olabilir; stability için kimlik bilgisi gerekir.
5. `sort()` kaynağı değiştirir, `toSorted()` yeni array verir.
6. Negatif: `a` önce; sıfır: eşit anahtar; pozitif: `b` önce.
7. Eşit puanlı kayıtların önceki kimlik sırası korunmalıdır.
8. Insertion sort, sıralı önekte az kaydırmayla ilerleyebilir.
