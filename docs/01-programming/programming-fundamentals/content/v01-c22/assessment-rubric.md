# Değerlendirme Rubriği

| Boyut | 4 — Güçlü | 3 — Yeterli | 2 — Gelişiyor | 1 — Başlangıç |
|---|---|---|---|---|
| Trace | İki algoritmada tüm state doğru | Normal iz doğru | Küçük iz hatası | İz kuramıyor |
| Değişmez | Başlatma/koruma/sonu savunur | Doğru cümle kurar | Eksik bağ | Tanımlayamıyor |
| Kod | Sonlanan, testli, sınırlar doğru | Temel durumlar doğru | Sınır/stability hatası | Çalışmıyor |

| İletişim | Değişken ve mutation açık | Ana kararlar açık | Terim karışıyor | Açıklayamıyor |
