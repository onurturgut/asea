# Kısa Özet

Selection sort kalan bölümün en küçüğünü seçer. Insertion sort yeni değeri
sıralı önekteki yerine kaydırarak yerleştirir. Stability eşit kayıtların göreli
sırasını korur. In-place ve orijinal veriyi koruma ayrı kararlardır. C23 için
karşılaştırma, swap ve shift sayıları saklanır.
