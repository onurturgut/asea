# Mini Proje — Sorting Workbench

Kullanıcı strateji, sıralama yönü ve örnek veri seçsin. Araç her dış turu,
karşılaştırma sayısını, swap/shift sayısını ve son sıralı sonucu göstersin.

İki mod:

- Öğrenme modu: adım adım state;
- Karşılaştırma modu: iki stratejinin ölçümleri.

Yeni framework gerekmez. Çıktı terminal veya mevcut admin lab görünümüne uygun
yapılandırılmış veri olabilir.
