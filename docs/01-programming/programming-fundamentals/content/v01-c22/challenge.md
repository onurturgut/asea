# Challenge — Comparator Sözleşmesi Tasarla

Algoritmaları `compare(first, second)` parametresiyle çalışacak biçime getirin.
ASEA chapter kayıtlarını önce zorluk, eşitse chapter ID’ye göre sıralayın.

Comparator:

- aynı çiftte tutarlı sonuç;
- `compare(a, a) === 0`;
- ters çiftlerde ters işaret;
- geçişli sıralama

üretmelidir. Normal, eşit anahtar ve ters sıra testleri ekleyin.
