# Alıştırmalar

1. `[5, 2, 4, 1]` selection sort dış turlarını izleyin.
2. Aynı girdiyi insertion sort ile izleyin.
3. Boş ve tek elemanlı array’de iki fonksiyonun sonucunu tahmin edin.
4. `[2, 2, 1]` üzerinde duplicate davranışını açıklayın.
5. `sort()` ile `toSorted()` arasındaki mutation farkını gösterin.
6. `(a, b) => a - b` comparator’ının üç olası sonuç işaretini açıklayın.
7. Eşit puanlı ayrı kimlikli kayıtlarla stability testi yazın.
8. Neredeyse sıralı küçük veri için seçim gerekçesi üretin.
