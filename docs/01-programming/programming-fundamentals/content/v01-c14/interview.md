# Mülakat Hazırlığı

1. Parameter ile argument arasındaki fark nedir?
2. JavaScript eksik ve fazla argument'ları nasıl ele alır?
3. Default parameter hangi değerlerde devreye girer?
4. Rest parameter ile spread syntax farkı nedir?
5. JavaScript parameter passing modelini nasıl açıklarsınız?
6. Primitive reassignment ile object mutation farkı nedir?
7. Aliasing hangi contract riskini oluşturur?
8. Bir parameter'ın necessary olduğunu nasıl kanıtlarsınız?
9. Unused, derived, duplicate ve hidden input farkları nelerdir?
10. Long parameter list'i ne zaman refactor edersiniz?
11. Options object ne zaman iyi, ne zaman yalnız torbadır?
12. Print ile return veri akışı nasıl farklıdır?
13. Tutarlı return shape neden önemlidir?
14. Function composition için hangi contract uyumu gerekir?
15. AI tarafından önerilen interface'i nasıl denetlersiniz?

Her cevapta küçük çağrı, sınır veya karşı örnek ve doğrulama kanıtı kullanın. En az iki soruyu data-flow diyagramıyla açıklayın.
