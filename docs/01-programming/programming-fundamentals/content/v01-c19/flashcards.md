# Bilgi Kartları

| Ön | Arka |
|---|---|
| Recursion | Problemi aynı problemin daha küçük örneğiyle çözme |
| Base case | Yeni recursive call yapmadan doğru sonuç veren durum |
| Recursive case | Daha küçük probleme çağrı ve sonucu birleştirme |
| Progress measure | Her çağrıda base case'e yaklaştığını gösteren ölçü |
| Call stack | Devam eden fonksiyon çağrılarını izleyen çalışma zamanı modeli |
| Call frame | Tek çağrının parametre, yerel değer ve dönüş noktasını taşıyan çerçevesi |
| Descent | Recursive çağrıların derinleştiği iniş fazı |
| Unwinding | Base case sonrası frame'lerin sonuç döndürdüğü çözülme fazı |
| Structural recursion | Çözümün kendine benzer veri tanımını izlemesi |
| Termination | Hesabın sonlu adımda durması |
| Stack depth | Aynı anda bekleyen call frame sayısı |
| Iterative alternative | Aynı davranışın döngü ve açık durumla kurulması |
