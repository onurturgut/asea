# C30 Quiz Cevap Anahtarı

1. `false`; her literal yeni kimlik üretir.
2. Binding'in başka value'ya yeniden atanmasını.
3. Bracket notation: `object[key]`.
4. `Object.hasOwn(object, key)` ile.
5. İkinci binding aynı object value'ya bağlanır.
6. Var olan object state'ini yerinde değiştirmektir.
7. Aynı object'e ulaşan birden fazla erişim yoludur.
8. Nested object referans değerleri aynen taşınır; kopya sığdır.
9. İlk argüman olan `target` object'ini.
10. Değişen property yolundaki object'ler.
11. Conversion boundary sözleşmesini aşar ve çağıran hatasını gizler.
12. Geçerli state'i tanımlayan type, invariant, identity ve mutation politikası gerekir.
