# V01-C01 Referans Chapter Paketi

## Purpose

`V01-C01 — Programlama Nedir?` ana dersini, uygulama ve değerlendirme
materyallerini C02 referans modeliyle aynı tek giriş noktası altında toplamak.

## Scope

Paket yalnız `V01-LO001` ve `V01-LO002` kapsamındadır. Bir programlama dilinin
ayrıntılı sözdizimi, bilgisayarın yürütme modeli ve veri türleri sonraki
chapter'lara bırakılır.

## Ownership

- Kanonik Chapter: `V01-C01@0.3.0`
- Chapter Blueprint: `V01-C01-BP01`
- Öğrenme çıktıları: `V01-LO001`, `V01-LO002`
- Değerlendirme: `V01-C01-AS01`
- Öğrenci içeriği sahibi: Software Engineering Educator
