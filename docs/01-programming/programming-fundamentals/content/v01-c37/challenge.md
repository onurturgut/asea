# C37 Meydan Okuma

Bir akademi ilerleme uygulamasını `domain`, `application`, `adapters` ve composition
root katmanlarına ayırın. Domain dış dünyayı import etmesin. Graph'ı Mermaid veya metin
ile gösterin; public API kararlarını, cycle bulunmadığını ve hata dönüşümünün hangi
boundary'de yapıldığını kısa bir teknik savunmayla açıklayın.
