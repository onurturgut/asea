# C37 Quiz Cevap Anahtarı

1. Tek, açıklanabilir sorumluluk ve korunacak public API kararı.
2. Tüketilebilen adları açık ve tutarlı kılar.
3. İsim/global state çakışmasını azaltır.
4. Export eden modüldeki güncel değerin tüketicide gözlenmesidir.
5. Import, dış modülün binding'ine read-only erişimdir.
6. State ownership kaybolur ve değişiklik kaynağı belirsizleşir.
7. Bir modülün başka modülden istediği bağımlılığı.
8. Initialization sırası ve sıkı bağ riski üretebilir.
9. Yalnız import etmek gözlenebilir iş başlatır.
10. Concrete bağımlılıkları kurup uygulamayı başlatmak.
11. Boundary'yi genişletir, refactor alanını daraltır.
12. JavaScript host'u ve kullanılan çalışma ortamı.
