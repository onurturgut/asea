# C37 Mini Proje — Öğrenme Kaydı Motoru

Öğrenci kaydı, ilerleme hesabı, rapor üretimi ve console görünümünü ayrı modüllerde
kurun. Clock ve output bağımlılıklarını application servisine parametre olarak verin.
Domain modülü `console`, `Date.now()` veya dosya sistemi kullanmasın. README içinde
public API tablosu ve dependency graph bulunsun.
