# C37 Kaynakları

- [ECMAScript Language: Scripts and Modules](https://tc39.es/ecma262/multipage/ecmascript-language-scripts-and-modules.html#sec-modules)
- [MDN: JavaScript modules](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules)
- [Node.js: ECMAScript modules](https://nodejs.org/api/esm.html)

Normatif davranış için ECMA-262, öğretim örnekleri için MDN, Node.js resolution ve runtime
ayrıntıları için Node.js belgesi kullanılır. Host'a özgü davranışlar dil standardıymış
gibi sunulmaz.
