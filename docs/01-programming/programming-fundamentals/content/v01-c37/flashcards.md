# C37 Bilgi Kartları

- **Module:** Kendi scope'u ve import/export sözleşmesi olan kaynak birimi.
- **Public API:** Diğer modüllerin kullanmasına izin verilen yüzey.
- **Module scope:** İsimlerin global yerine modül içinde yaşaması.
- **Live binding:** Export edilen binding'in güncel değerini gözleme.
- **Dependency graph:** Modüller ve import ilişkilerinin modeli.
- **Cycle:** Graph'ta bir modülden tekrar kendisine ulaşan yol.
- **Composition root:** Concrete bağımlılıkları birleştiren başlangıç noktası.
- **Side effect:** Dönen değerin dışında gözlenebilir durum değişikliği.
