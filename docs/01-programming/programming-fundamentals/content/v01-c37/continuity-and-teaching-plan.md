# C37 Devamlılık ve Öğretme Planı

C16'nın sorumluluk ayırımı, C33'ün state ownership'i ve C36'nın hata sınırları bu
chapter'da gerçek dosya sınırlarına dönüşür. İhtiyaçtan sezgiye, küçük named export
örneğinden dependency graph analizine ilerlenir. Öğrenci önce birlikte ayrıştırır,
sonra hata avı yapar ve P08'i bağımsız olarak modüllere böler. C38'e devredilen
yeterlik, bir programı test edilebilir public API'lere sahip bir graph olarak okuyabilmektir.
