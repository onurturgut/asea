# C37 Alıştırmaları

1. Tek dosyadaki doğrulama, hesaplama ve çıktı işlerini üç sorumluluğa ayırın.
2. Her modülün minimum public API'sini named export ile yazın.
3. Import listesinden dependency graph çizin ve olası cycle'ı işaretleyin.
4. Import edildiğinde log yazan modülü side-effect içermeyecek biçimde düzenleyin.
5. Export edilen mutable object yerine kontrollü bir fonksiyon API'si tasarlayın.
