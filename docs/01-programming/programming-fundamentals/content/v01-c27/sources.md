# Kaynaklar

- [Refactoring — Martin Fowler](https://refactoring.com/): küçük behavior-preserving dönüşümler ve refactoring sınırı.
- [Google JavaScript Style Guide](https://google.github.io/styleguide/jsguide.html): açıklayıcı naming ve JavaScript kod standardı örnekleri.
- [Google Documentation Best Practices](https://google.github.io/styleguide/docguide/best_practices.html): anlamlı isimler ve yorumların koddan çıkarılamayan bilgiyi taşıması.
- [Node.js Test Runner](https://nodejs.org/api/test.html): refactoring güvenlik ağının çalıştırılması.

Kaynaklar teknik kararları doğrular; ASEA anlatımı öğrenciyi sonuçtan önce küçük
adım ve test kanıtı üretmeye yönlendirir.
