# Mini Proje — Refactoring Karar Günlüğü

Bir kod parçası ve refactoring adımlarını kaydeden JavaScript veri modeli oluşturun.
Her kayıt `smell`, `risk`, `change`, `testsBefore`, `testsAfter`, `metricsBefore`,
`metricsAfter` ve `decision` alanlarını taşısın.

Araç davranış değiştiğinde adımı “refactoring” olarak tamamlamamalı; inceleme
gerektiren değişiklik olarak işaretlemelidir. Yalnız satır sayısını başarı metriği
yapmayın.
