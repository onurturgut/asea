# Alıştırmalar

1. `calc(s)` örneğinde beş smell bulun ve her birini bakım riskiyle ilişkilendirin.
2. Yalnız rename adımını uygulayıp baseline test sonuçlarını karşılaştırın.
3. Magic number’lardan hangilerini constant yapacağınızı gerekçelendirin.
4. Aynı görünen iki kod parçasının gerçek duplication olup olmadığını “aynı
   nedenle değişme” sorusuyla değerlendirin.
5. Before/after readability, cohesion, duplication ve complexity tablosu yazın.
