# Mülakat Soruları

## Ana soru

“Clean code ölçütlerini kişisel zevkten nasıl ayırırsınız?”

Güçlü cevap; ekip sözlüğü, değişiklik riski, readability, cohesion, duplication,
complexity ve test kanıtını kullanır; tek stil tercihini evrensel kural yapmaz.

## Takip soruları

- Refactoring ile rewrite arasındaki fark nedir?
- Her duplication neden hemen kaldırılmamalıdır?
- Testler yetersizse nasıl güvenli ilerlersiniz?
- Bir yorum ne zaman koddan daha değerli bilgi taşır?
- Refactoring PR’ına feature eklemek review’u neden zorlaştırır?
