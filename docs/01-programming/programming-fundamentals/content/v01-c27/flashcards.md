# Bilgi Kartları

- **Readability:** Kodun niyet ve akışını doğru anlama maliyeti.
- **Code smell:** Olası bakım riskine işaret eden belirti.
- **Refactoring:** Observable behavior’ı koruyan iç yapı dönüşümü.
- **Semantic preservation:** Dış sözleşmenin değişiklik boyunca aynı kalması.
- **Rename:** İsmi davranışı değiştirmeden açıklayıcı hâle getirme.
- **Extract Function:** Anlamlı kod bölümünü isimli fonksiyona taşıma.
- **Cohesion:** Parçaların aynı sorumluluk/değişiklik nedeni etrafında birleşmesi.
- **Duplication:** Aynı bilginin birden fazla bağımsız kaynağı.
- **Magic number:** Domain anlamı isimsiz bırakılmış sayısal literal.
- **Cognitive complexity:** Kontrol akışını anlamanın zihinsel karar yükü.
- **Behavior-preserving:** Gözlenebilir sonucu değiştirmeyen.
- **Rewrite:** Geniş kod bölümünü yeniden kuran, refactoring’den daha riskli değişim.
