# Chapter Özeti

C27’de code smell’i bakım riski sinyali olarak değerlendirdiniz. C26’nın yeşil
suite’i altında rename, introduce constant ve extract function dönüşümlerini küçük
adımlarla uyguladınız. Her adımda observable behavior’ın korunduğunu test ettiniz.
Sonucu readability, cohesion, duplication ve complexity before/after kanıtlarıyla
savundunuz; feature, bug fix, refactoring ve rewrite sınırlarını ayırdınız.
