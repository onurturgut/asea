# Görselleştirme Notları

## Refactoring döngüsü

Yeşil test → tek dönüşüm → test → pass ise kayıt, fail ise geri al/incele akışı.
Feature ekleme ayrı bir dış dal olarak gösterilmelidir.

## Before/after tablo

İsim, sorumluluk, kural kaynağı, karar derinliği ve test sonucu yan yana verilmeli.
“Daha iyi” tek renk veya puanla değil ölçüt bazında açıklanmalıdır.

## Davranış sınırı

59, 60 ve 61 dakika sayı doğrusunda `>=` ile `>` farkı görünür yapılmalı.
