# Alıştırma Çözümleri

1. Anlamsız function/parameter/field/result adları ve adsız domain sayıları yanlış
   alanı değiştirme veya kuralı kaçırma riskini artırır.
2. Rename sonrası bütün expected skorlar aynı kalmalıdır; aksi davranış değişimidir.
3. 2, 10, 60 ve 5 domain kuralıdır; accumulator başlangıcı 0 yerel ve açıktır.
4. Yalnız metinsel benzerlik yetmez. Aynı iş bilgisini temsil edip birlikte
   değişiyorlarsa tek kaynak değerlidir.
5. Sonuç, yalnız satır sayısına değil isimlerin anlamına, sorumluluk sınırına,
   kural kopyalarına, karar yüküne ve test kanıtına dayanmalıdır.
