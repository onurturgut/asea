# Mini Proje — Envanter Veri İşleyici

JSON benzeri ham ürün kayıtlarını doğrulayan, geçerli kayıtları normalize eden ve
geçersiz kayıtları yapılandırılmış hata raporuyla ayıran küçük bir komut satırı
çekirdeği geliştirin.

Çıktı; geçerli kayıt sayısı, reddedilen kayıt sayısı, hata kodlarına göre dağılım
ve yeniden sipariş gereken ürünleri içermelidir. Ham kaynak koleksiyon değişmemeli;
model karar tablosu, değişmezler ve en az 16 test teslim edilmelidir.
