# Proje Artışı — Güvenilir Girdi Modeli

Ana projenin girdisini serbest nesnelerden açık bir kayıt modeline taşıyın.
Gereksinim–alan tablosu, construction boundary, yapılandırılmış hata sonucu ve en
az üç değişmez ekleyin. Eski geçerli örneklerin çalışmaya devam ettiğini, geçersiz
örneklerin ise işlem hattına girmediğini test edin.

Commit/teslimat notunda şu kararı açıklayın: Hangi alan kaynak veri, hangi alan
türetilmiş veri ve modelinizin doğruluk kaynağı nedir?
