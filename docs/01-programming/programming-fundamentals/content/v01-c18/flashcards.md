# Bilgi Kartları

| Ön | Arka |
|---|---|
| Record | Tek varlık/olayı anlatan adlandırılmış alanlar bütünü |
| Field | Kayıt içindeki tek anlamlı veri parçası |
| Schema | İzin verilen yapı ve kısıtların sözleşmesi |
| Instance | Şemaya göre oluşturulmuş gerçek değer |
| Invariant | Model geçerliyken doğru kalması gereken koşul |
| Invalid state | En az bir değişmezi ihlal eden durum |
| Construction boundary | Ham veriden geçerli domain kaydı üreten sınır |
| Identity | Bir varlığı zaman içinde aynı varlık yapan ayırt edici |
| Reference equality | İki değişkenin aynı nesneyi gösterip göstermemesi |
| Derived data | Başka alanlardan hesaplanabilen veri |
| Runtime validation | Program çalışırken dış verinin kontrolü |
| Data minimization | Yalnız amaç için gereken veriyi toplama ilkesi |
