# Görsel Tasarım Notları

## 1 — Diziden Kayda

Üç paralel dizide indeks hizası riskini, aynı değerlerin tek kayıt kartında
adlandırılmış alanlara dönüşümünü gösteren karşılaştırmalı görsel.

## 2 — Doğrulama Katmanları

Ham veri → runtime validation → domain record → operation → storage akışını,
hata çıkışlarını ve her katmanın farklı sorumluluğunu gösteren şema.

## 3 — Geçerli Durum Alanı

Bütün mümkün nesne kombinasyonlarını büyük alan, değişmezleri sağlayan kayıtları
içte küçük alan olarak göster. Construction boundary okları yalnız küçük alana
girebilsin.

Görseller renk dışında etiket ve ikonla anlam taşımalı; kod ile aynı alan adlarını
kullanmalı; dekoratif 3B efekt içermemelidir.
