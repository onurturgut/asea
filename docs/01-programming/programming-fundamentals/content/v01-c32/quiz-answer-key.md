# C32 Quiz Cevap Anahtarı

1. Binding, property ve argument olarak taşınabilen callable object'tir.
2. Function value ve invocation return value.
3. Function kabul etmek veya function döndürmek.
4. Function'ın başka caller'a çağrılmak üzere verilmesi ilişkisi.
5. Higher-order/host API; argument, order/count, return ve error contract'ıyla.
6. Bir koşulun boolean bağlamındaki kararını.
7. Mapper element output'u, reducer yeni accumulator döndürür.
8. Map index'i verir; parseInt onu radix olarak yorumlar.
9. İki signature'ın parameter anlamını uyumlar.
10. Hayır; çoğu array callback'i senkrondur.
11. Tekrarlanan çağrı dış state'i birden çok kez değiştirebilir.
12. Lexical capture ve retained lifetime ayrı zihinsel model gerektirir.
