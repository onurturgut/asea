# C32 Bilgi Kartları

## Kartlar

- **Function value?** Çağrılabilir object value.
- **Function reference?** Function'ı çağırmadan taşıyan value erişimi.
- **Invocation?** Call expression ile function body'nin çalıştırılması.
- **Higher-order function?** Function kabul eden veya döndüren function.
- **Callback?** Çağrılma yetkisi başka caller'a verilen function.
- **Caller?** Callback'i ne zaman ve nasıl çağıran taraf.
- **Callback contract?** Arguments, return, count/order, timing ve error sözleşmesi.
- **Predicate?** Karar değeri döndüren callback.
- **Mapper?** Output element üreten callback.
- **Comparator?** Göreli sıra için number döndüren callback.
- **Adapter?** Uyuşmayan signature anlamlarını bağlayan wrapper callback.
- **Side effect?** Return dışında gözlenebilir state değişimi.
