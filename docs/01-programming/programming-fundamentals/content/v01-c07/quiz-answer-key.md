# Operatörler ve İfadeler — Cevap Anahtarı

## Kullanım Uyarısı

Bu dosyayı yalnız [quiz](./quiz.md) cevaplarını kilitledikten sonra aç. Yanlış cevabı yalnız
harfle düzeltme; açıklamayı kendi değerlendirmenin hangi adımını atladığınla eşleştir.

## Yanıtlar ve Açıklamalar

1. **B.** Çarpma önce gruplanır: `3 + (4 * 5) = 23`.
2. **A.** İşlenen, işlecin uygulandığı değer veya alt ifadedir.
3. **B.** Çıkarma soldan birleşir: `(10 - 3) - 2`.
4. **C.** Üs alma sağdan birleşir: `2 ** (3 ** 2) = 512`.
5. **B.** String işlenen nedeniyle `+` metin birleştirme yapar.
6. **B.** `-` sayısal dönüşüm ister ve Number 3 üretir.
7. **C.** Önce Number 3, sonra String "33" oluşur.
8. **A.** İlk işlemden itibaren metin birleştirme sürer.
9. **B.** Sıkı eşitlik tür dönüştürmez; Number ile String eşit değildir.
10. **C.** `Number.isNaN` gerçek `NaN` değerini denetler.
11. **B.** Number bölmesi `Infinity` üretir; domain yine de geçersiz olabilir.
12. **C.** Remainder sonucu bölünenin işaretini izler.
13. **B.** Öncelik, işleç düğümlerinin nasıl gruplanacağını belirler.
14. **A.** Aynı öncelikteki işleçlerin gruplama yönünü belirler.
15. **C.** İşlenen ifadeleri soldan sağa değerlendirilir; gruplama bununla aynı şey değildir.
16. **B.** Sonek biçim önce eski değeri üretir, sonra bağlamayı artırır.
17. **B.** `+=` içindeki `+`, String nedeniyle birleştirme yapar.
18. **B.** İki literal iki farklı nesne kimliği oluşturur.
19. **B.** Bazı ondalıklar ikili kayan noktada tam temsil edilemez.
20. **C.** Number ve BigInt aritmetikte doğrudan karıştırılamaz.
21. **B.** Ara değerler domain aşamalarını, türleri ve test noktalarını görünür yapar.
22. **C.** Parantez doğrulama veya tür dönüşümü sağlamaz.
23. **C.** Sayfa sözleşmesi 1'den başlar; `page=0` geçersizdir.
24. **B.** İlk sapmayı bulmak hatanın gerçek kaynağını yalıtır.
25. **C.** AI yanıtı kanıt değildir; resmi semantik ve yürütme iziyle doğrulanır.

## Sonuç Yorumlama

- **23–25:** Güçlü; laboratuvar ve challenge'a geç.
- **20–22:** Geçer; yanlış kuralları tekrar edip düşük güvenli soruları yeniden çöz.
- **16–19:** Ana dersteki değerlendirme protokolünü üç yeni ifadede uygula.
- **0–15:** C05 tür dönüşümleri ve C06 durum izleme bölümlerini tekrar et.
