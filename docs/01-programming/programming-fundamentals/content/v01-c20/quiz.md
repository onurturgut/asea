# V01-C20 Mini Quiz

1. String'in immutable olması ne demektir?
2. `trim()` metnin hangi bölümünü etkiler?
3. `"   ".trim()` sonucu nedir?
4. Türkçe başlık aramasında locale neden açık olmalıdır?
5. Unicode normalization ile case conversion aynı işlem midir?
6. `"".split(/\s+/)` sonucunu doğrudan kelime saymak neden hatalıdır?
7. Tokenization ile validation farkı nedir?
8. `rawTitle` ve `searchTitle` neden ayrı tutulur?
9. `"🦊".length` neden kullanıcının gördüğü karakter sayısıyla uyuşmayabilir?
10. Beş aşamalı güvenilir bir başlık pipeline'ı yazın.
