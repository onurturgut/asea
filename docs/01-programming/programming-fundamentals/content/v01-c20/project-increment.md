# V01-P05 Metin İşleme Artışı

## C19'dan Gelen

İç içe öğrenme gruplarından toplanan ham başlıklar.

## C20'de Eklenen

- Ham/display/search temsil ayrımı.
- NFC ve `tr-TR` politikası.
- Whitespace tokenization ve empty-input sözleşmesi.
- Canonical title ve word count.
- Normal, Turkish case, Unicode ve empty test matrisi.

## C21'e Devredilen

`canonicalTitle` değerlerinden oluşan aranabilir string array'i. C21 hedef
başlığın bu koleksiyonda nasıl aranacağını inceleyecek.
