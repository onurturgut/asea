# V01-C20 Bilgi Kartları

1. **String immutable ne demek?** İşlem özgün değeri değiştirmez, yeni değer üretir.
2. **`trim()` ne yapar?** Baş ve son whitespace'i kaldırır.
3. **Normalization nedir?** Metni belgelenmiş ortak temsile getirme.
4. **NFC ne sağlar?** Kanonik eşdeğer Unicode dizilerini ortaklaştırabilir.
5. **Locale neden açık?** Dil-duyarlı case politikasını belirler.
6. **Token nedir?** Sonraki işlem için ayrılmış metin parçası.
7. **Empty input token sonucu?** Bu chapter sözleşmesinde `[]`.
8. **Parsing nedir?** Metni yapısal parçalara dönüştürme.
9. **Validation nedir?** Parçaların kurallara uygunluğunu sınama.
10. **Code unit nedir?** JavaScript UTF-16 depolama/indeksleme birimi.
11. **Code point nedir?** Unicode'daki soyut karakter değeri.
12. **Grapheme nedir?** Kullanıcının çoğunlukla tek karakter algıladığı küme.
