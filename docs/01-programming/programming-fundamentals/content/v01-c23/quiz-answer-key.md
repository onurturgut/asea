# Mini Quiz Açıklamalı Cevapları

1. Girdiyi büyüten bağımsız nicelik probleme göre değişir; iki koleksiyon için
   `n` ve `m`, sayı problemi için basamak sayısı anlamlı olabilir.
2. `Θ(n)`. Sabit katsayı ve toplama terimi uzun dönem büyümesini değiştirmez.
3. `Θ(n)`: `n + n = 2n`.
4. Hayır. O(n) asimptotik bir üst sınırdır, tam işlem eşitliği değildir.
5. İkili arama sıralı veri ister; sıralama ve bakım maliyeti küçük/tek seferlik
   aramada kazancı aşabilir.
6. Karmaşıklık `n` büyürken işin büyümesini modeller; süre ortamdan etkilenen
   deneysel bir ölçümdür.
7. Ek bellek, sabit maliyet, okunabilirlik, veri boyutu, güncelleme sıklığı ve
   doğruluk ön koşullarıyla.
