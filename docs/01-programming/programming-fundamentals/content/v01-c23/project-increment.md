# Proje Artımı — V01-P06 Algorithm Workbench

P06'ya “Analiz” görünümü ekleyin. Kullanıcı bir algoritma ve veri seti seçtiğinde
girdi boyutu, temel işlem sayısı, ölçülen süre, tahmini büyüme sınıfı ve karar
notu görüntülensin.

Bu artımda sonuçların kalıcı olması zorunlu değildir. Ancak ölçüm fonksiyonu,
algoritma uygulamasından ayrılmalı; sonraki chapterlarda test edilebilmelidir.
