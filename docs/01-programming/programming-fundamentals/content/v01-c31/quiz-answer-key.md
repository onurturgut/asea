# C31 Quiz Cevap Anahtarı

1. Array de object'tir; `Array.isArray` gerekir.
2. `undefined`.
3. En az bir eşleşme ve bütün elementlerin eşleşmesi.
4. Hayır; truthy/falsy kararla mevcut elementi seçer.
5. Düzenli array'de aynı length.
6. Accumulator başlangıç state'i/type'ı ve empty-input sonucu.
7. Element sırasını yerinde değiştirir.
8. Root array identity'sini; object elementler paylaşılabilir.
9. Hayır, kopya shallow'dur.
10. `undefined` output elementleri.
11. `false` ve `true`.
12. Ownership, aliasing, geçmiş state, okunabilirlik ve ölçülmüş maliyet.
