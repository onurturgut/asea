# C31 Bilgi Kartları

## Kartlar

- **Array doğrulaması?** `Array.isArray(value)`.
- **Index?** Array elementine erişen sıfır tabanlı key.
- **Cardinality?** Bir aşamadaki element sayısı.
- **Predicate?** Element için koşul sonucu üreten callback.
- **`find`?** İlk eşleşen element veya `undefined`.
- **`some`?** En az bir eşleşme için boolean.
- **`every`?** Bütün elementler için boolean.
- **`filter`?** Uyan elementlerden yeni array.
- **`map`?** Her element için yeni output value.
- **`reduce`?** Koleksiyonu accumulator ile tek sonuca birleştirme.
- **Mutating operation?** Source array state'ini yerinde değiştiren işlem.
- **Shallow array copy?** Yeni root, paylaşılabilen object elementler.
