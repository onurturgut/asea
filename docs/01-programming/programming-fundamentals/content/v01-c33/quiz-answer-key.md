# C33 Quiz Cevap Anahtarı

1. Lexical environment binding erişimi ilişkisini de içermelidir.
2. Function object'in oluşturulduğu environment ile ilişkisi sayesinde.
3. Binding'in güncel value'su sonraki call'da çözümlenir.
4. Frame biter; reachable closure environment erişimini koruyabilir.
5. Her call yeni function environment oluşturur.
6. Aynı invocation environment binding'lerini çözerler.
7. Const binding'i sabitler, object property state'ini değil.
8. Dış mutation invariant'ı atlar ve snapshot isolation'ı bozar.
9. Command state değiştirir; query gözlemler.
10. Iteration'lar için ayrı lexical binding davranışı sağlar.
11. Uzun yaşayan callback gereksiz büyük captured graph'a erişimi korursa.
12. Program interface erişimini sınırlar; untrusted-code security garantisi değildir.
