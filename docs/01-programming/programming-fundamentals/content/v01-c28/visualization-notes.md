# Görselleştirme Notları

## Ana akış

```text
İhtiyaç → Scope → Requirement → Acceptance criterion
                         ↓
       Data model → Function map → Implementation
                         ↓
       Tests → Traceability → Risk → Technical review → Delivery
```

## Sağ panel kartları

- İngilizce Terimler
- Requirement–Test Trace
- Acceptance Criteria
- Risk Register
- Test Sonuçları
- Kısa Notlar
- AI Mentor

Trace kartında requirement seçildiğinde bağlı tasarım kararı, kod sembolü ve test
durumu birlikte gösterilmelidir. Kırık bağlantı uyarı rengiyle görünür olmalıdır.
