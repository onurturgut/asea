# Capstone Proje Artışı

`V01-CP01 — Reliable Command-Line Problem Solver` için:

- requirement ve acceptance criteria setini dondurun,
- data model ve function map'i son kodla eşleyin,
- her kritik requirement'ı teste bağlayın,
- C24–C27 failure, test ve refactoring kanıtlarını ekleyin,
- risk register, known limitations ve rejected alternatives yazın,
- çalıştırma yönergesi ve test çıktısını kaydedin,
- teknik review bulgularını kapatın veya açık risk olarak teslim edin.
