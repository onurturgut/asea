# Kısa Özet

C28, Volume 01'in bütünleştirme kapısıdır. Öğrenci belirsiz ihtiyeti kapsamı açık,
ölçülebilir requirement ve acceptance criteria setine dönüştürür. Data model,
function map, implementation ve test planını kurar.

Her requirement gerçek kod ve test kanıtına bağlanır. Verification ile validation
ayrılır; risk, mitigation, limitation ve rejected alternative saklanmadan teslim
edilir. Teknik review sonunda öğrenci yalnız programı değil, programın neden doğru,
bakımı yapılabilir ve teslim edilebilir olduğunu savunur.
