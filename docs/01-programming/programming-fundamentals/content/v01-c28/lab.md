# Lab — Program Design Dossier

**ID:** `V01-C28-L01`
**Süre:** 120 dakika
**Outcome:** `V01-LO046`

## Senaryo

Bir çalışma planı, bütçe özeti veya kütüphane gecikme programı seçin. Framework,
network ve database kullanmayın.

## Teslimler

1. Problem statement, stakeholder, scope, non-goals ve assumptions.
2. En az altı kimlikli requirement ve acceptance criteria.
3. Data dictionary, function map ve pseudocode.
4. Controlled failure policy.
5. Çalıştırılabilir modüler JavaScript programı.
6. En az 10 test: normal, boundary, invalid ve regression.
7. Requirement → design → code → test → review traceability matrix.
8. En az üç risk, mitigation ve residual limitation.
9. Bir rejected alternative ve teknik gerekçe.
10. Çalıştırma yönergesi, test çıktısı ve delivery decision.

## Başarı kapısı

Kritik requirement'ların tamamı kanıtlanmalı, testler geçmeli ve öğrenci iki
tasarım kararını sözlü savunmalıdır. Dosya varlığı tek başına başarı değildir.
