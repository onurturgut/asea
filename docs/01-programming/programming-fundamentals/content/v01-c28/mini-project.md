# Mini Proje Kararı

C28 için ayrı bir Mini Project yoktur. Chapter, önceki altı Mini Project'ten gelen
kanıtları `V01-CP01` Capstone tesliminde birleştiren integration gate'tir.

Öğrenci yeni ve bağımsız bir ürün başlatmak yerine mevcut proje omurgasının problem
contract, design, implementation, test, review ve delivery kanıtlarını tek dossier'a
toplar. Eksik eski kanıt bulunduğunda geriye dönük bağlantı kurar veya ilgili
chapter kapısına döner.
