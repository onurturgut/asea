- [Google — What to Look for in a Code Review](https://google.github.io/eng-practices/review/reviewer/looking-for.html): design, functionality, complexity, tests ve documentation incelemesi.
- [Google — The Standard of Code Review](https://google.github.io/eng-practices/review/reviewer/standard.html): kişisel tercih yerine teknik gerçek ve code health.
- [Google — Small CLs](https://google.github.io/eng-practices/review/developer/small-cls.html): küçük ve incelenebilir değişiklikler.
- [ASEA Teaching Standard](../../../../standards/teaching-and-continuity-standard-v1.md): öğretim ve devamlılık sözleşmesi.
