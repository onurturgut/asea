# Mülakat Hazırlığı

1. Functional decomposition nedir ve function extraction'dan nasıl farklıdır?
2. Bir function boundary'sini hangi ölçütlerle seçersiniz?
3. Responsibility map ile function map arasındaki fark nedir?
4. Abstraction level karışıklığını nasıl fark edersiniz?
5. Cohesion'ı function length dışında nasıl değerlendirirsiniz?
6. Coupling hangi görünür ve gizli kanallardan oluşur?
7. Loose coupling neden zero dependency değildir?
8. Uzun parameter list extraction hakkında ne söyleyebilir?
9. Orchestration ile domain calculation nasıl ayrılır?
10. Pipeline'da contract compatibility nasıl doğrulanır?
11. Reuse ile composition arasındaki fark nedir?
12. İki duplicate block'u ne zaman birleştirmezsiniz?
13. Characterization tests refactoring'de neden önemlidir?
14. İki decomposition seçeneğini nasıl karşılaştırırsınız?
15. AI tarafından önerilen modüler tasarımı nasıl denetlersiniz?

Her cevapta definition, concrete example, trade-off ve evidence kullanın. En az
iki soruyu function map, ikisini change-scenario matrix ile açıklayın.
