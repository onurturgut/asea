# C34 Kartları

- binary64: Number representation yönelimi
- finite: NaN/Infinity olmayan
- safe integer: distinguishable exact integer sınırı
- tolerance: domain kabul farkı
- rounding: value'yu seçilmiş grid'e taşıma
- minor unit: para alt birimi integer modeli
- formatting: presentation string üretimi
