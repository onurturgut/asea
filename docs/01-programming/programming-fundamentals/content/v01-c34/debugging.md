# C34 Hata Ayıklama

Value, type, finite, integer, safe-integer, unit ve operation sırasını kaydedin.
Formatted string'i calculation hattına sokan ilk satırı; rounding'in ilk uygulandığı
noktayı ve unsafe conversion boundary'sini bulun.
