# V01-C38 Mini Quiz Açıklamalı Cevaplar

1. Kaynak dosya diskte duran talimat metnidir; process runtime tarafından
   başlatılmış, girdileri ve çalışma durumunu taşıyan yürüyen program örneğidir.

2. **C — `document.title`.** `const`, toplama ve string literal dil
   kurallarıdır; `document` web sayfası bağlamını tarayıcı host'undan alır.

3. `report.js`. `node` CLI/runtime başlatıcısı, `Ada` ve `85` kullanıcı
   argümanlarıdır.

4. İlk kullanıcı argümanını taşır ve komut satırından geldiği için string'dir.
   Argüman yoksa değer `undefined` olabilir.

5. `node .\c38\app.js`. Alternatif olarak önce `cd .\c38`, sonra
   `node app.js` çalıştırılabilir.

6. `console.error` hata metnini stderr'e yöneltir; `process.exitCode = 1`
   sürecin makine-okunur başarısızlık durumunu belirler. İnsan mesajı ile
   otomasyon sonucu ayrı kanıtlardır.

7. `process.argv[2]` `"50"` string'idir. `+`, string bulunduğunda metin
   birleştirme davranışı gösterebilir. Açık sınır:
   `const numberValue = Number(value);`.

8. `--` sonrasındaki konumsal değerleri npm'in kendisine seçenek olarak vermek
   yerine seçilen script'in komutuna aktarır.

9. Uygun altılı: runtime sürümü, işletim sistemi, çalışma klasörü, giriş
   noktası, tam komut, argüman/girdi sözleşmesi, beklenen çıktı, gerçek çıktı,
   exit status, bilinen sınırlar. İlk altı tek başına kabul edilebilir; çıktı ve
   durumun da bulunması güçlü yanıttır.

10. Kodun Node.js gibi `document` sağlamayan bir host'ta çalışıp çalışmadığını
    araştırırım. Önce ürünün tarayıcı sayfası mı terminal programı mı olması
    gerektiğini doğrularım.
