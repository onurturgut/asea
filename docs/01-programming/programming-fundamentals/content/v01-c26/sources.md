# Kaynaklar

- [Node.js Test Runner](https://nodejs.org/api/test.html): JavaScript testlerini tanımlama, çalıştırma ve failure raporlama.
- [Node.js Assert](https://nodejs.org/api/assert.html): invariant, strict ve deep equality assertion davranışları.
- [ISTQB CTFL Syllabus v4.0.1](https://istqb.org/wp-content/uploads/2024/11/ISTQB_CTFL_Syllabus_v4.0.1.pdf): equivalence partitioning, boundary value analysis ve coverage kavramları.

Kaynaklar teknik doğrulama içindir. Öğrenci önce framework bağımsız test zihinsel
modelini öğrenir; araç sözdizimi daha sonra bu modelin üzerine yerleştirilir.
