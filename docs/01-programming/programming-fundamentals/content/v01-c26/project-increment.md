# Proje Artımı — V01-CP01 Test Güvenlik Ağı

Capstone’a şu test gruplarını ekleyin:

- normal davranış,
- alt/üst boundary,
- invalid type ve değer,
- C25 defect’i için regression.

Her testte oracle kaynağı görünür olsun. Suite sonunda risk coverage ve kör nokta
raporu üretin. Bu güvenlik ağı C27’de behavior-preserving refactoring kapısıdır.
