# Mülakat Soruları

## Ana soru

“Test coverage neden tek başına kalite kanıtı değildir?”

Güçlü cevap; çalıştırılan satır ile doğru oracle/assertion ayrımını, boundary ve
risk seçimini, isolation ve integration kör noktalarını açıklar.

## Takip soruları

- 0–100 aralığı için hangi testleri seçersiniz ve neden?
- Regression testinin önce fail ettiğini neden görmek istersiniz?
- Unit test ile integration test hangi farklı riskleri taşır?
- Implementation detail’e bağlı test refactoring’i nasıl etkiler?
- Bir test suite’in kör noktalarını nasıl raporlarsınız?
