# Lab — Boundary Odaklı Test Suite Tasarla

## Görev

1. Verilen fonksiyon contract’ını test edilebilir maddelere ayırın.
2. Normal, boundary ve invalid equivalence partition’ları oluşturun.
3. Her test için oracle kaynağını ve expected sonucu koddan önce yazın.
4. Assertion’larla çalışan izole test suite üretin.
5. C25’ten gelen defect için önce fail eden regression testi gösterin.
6. Testlerin farklı sırada aynı sonucu verdiğini kontrol edin.
7. Risk coverage, güven düzeyi ve en az beş kör nokta raporlayın.

Bonus: Contract’tan üç property-based testing invariant’ı önerin; araç kullanımı
zorunlu değildir.
