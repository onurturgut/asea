# Chapter Özeti

C26’da sözleşmeyi normal, boundary ve invalid testlere dönüştürdünüz. Expected
sonucu bağımsız oracle’dan aldınız; assertion ile actual farkını görünür yaptınız.
Unit testleri izole tuttunuz ve C25 failing case’ini fix öncesi fail eden regression
testine çevirdiniz. Coverage metriğini kalite puanı saymak yerine eksik riskleri
bulmakta kullandınız; suite’in kapsadığı riskleri ve kör noktaları raporladınız.
