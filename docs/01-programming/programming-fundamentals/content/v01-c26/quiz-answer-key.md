# Mini Quiz Açıklamalı Cevapları

1. Ad, başlangıç, girdi, expected, actual ve pass/fail kararı.
2. Expected sonucun doğru olduğunu belirleyen bağımsız bilgi kaynağıdır.
3. Test ve kod aynı defect’i tekrar edip yeşil kalabilir.
4. Kodun actual sonucu ile oracle’dan gelen expected sonuç.
5. Normal temsilî ana davranış, boundary davranışın değiştiği kenardır.
6. Aynı işlenmesi beklenen sonsuz girdiden anlamlı temsilci seçmek için.
7. `-1`, `0`, `100`, `101`.
8. Test sırası ve ortak state failure nedenini değiştirmemelidir.
9. Mümkünse fix’ten önce ve doğru nedenle fail ettiği görülerek.
10. Yanlış davranışı ölçüyor veya oracle zayıf olabilir.
11. Oracle doğruluğu, boundary/risk seçimi ve integration davranışını.
12. Risk, onu ölçen testler, güven düzeyi ve bilinen kör noktalar.
