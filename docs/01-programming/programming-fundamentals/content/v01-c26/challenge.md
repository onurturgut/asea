# Challenge — Regression’ı Tekrarlanabilir Yap

C25 debugging dossier’ındaki bir defect’i seçin. Minimal failing case’i test
case’e dönüştürün ve şu kırmızı–yeşil kanıtı üretin:

1. Bozuk implementation’da doğru nedenle fail.
2. Root cause fix’inden sonra pass.
3. Komşu normal ve boundary testleri pass.
4. Test sırası değişince sonuç aynı.

Ardından bu regression testinin hangi kusuru yakalayacağını ve hangi benzer
kusurları yakalamayacağını açıklayın.
