# Görselleştirme Notları

## Debugging hunisi

Geniş failure alanından reproduction, minimal case, hipotez, deney ve root cause’a
daralan bir huni. Fix huninin sonunda gösterilmeli; başlangıçta çözüm gibi sunulmamalı.

## Hipotez matrisi

Satırlar H1–H3; sütunlar önerme, deney, beklenen kanıt, gerçek kanıt ve durum.
Elenen hipotezler silinmemeli, üstü çizili “elendi” etiketiyle korunmalıdır.

## Çalışma izi

Döngü turlarında index, length, value ve total değerleri tabloyla gösterilmeli.
`undefined → NaN` yayılımı oklarla belirtilmeli; renk tek anlam taşıyıcısı olmamalı.
