# Proje Artımı — V01-CP01 Debugging Günlüğü

C24 error contract senaryolarından biri için Capstone’a debugging dossier ekleyin:

- yeniden üretim tarifi,
- minimal failing case,
- üç hipotez ve deney,
- root cause açıklaması,
- minimal fix,
- boundary ve regression risk listesi.

Bu dosya C26’da otomatik regression testinin gerekçesi ve girdi kaynağı olacaktır.
