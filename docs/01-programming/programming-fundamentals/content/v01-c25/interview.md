# Mülakat Soruları

## Ana soru

“Çalışmayan bir programı ilk beş adımda nasıl araştırırsınız?”

Güçlü cevap: expected/observed kaydı, güvenli reproduction, minimal case, gözlem
ve en az üç hipotez, kontrollü deney. Aday hemen kod değiştirmemeli ve root cause
ile symptom’u ayırmalıdır.

## Takip soruları

- Yeniden üretilemeyen bir failure’da nasıl ilerlersiniz?
- Log yerine breakpoint’i ne zaman seçersiniz?
- İlk hipotezinize bağlanmayı nasıl önlersiniz?
- Fix’in regression üretmediğini nasıl kontrol edersiniz?
- Git bisect hangi koşullarda araştırmayı hızlandırır?
