# Challenge — Failing Case’i Küçült

Size verilen 30 satırlık, beş girdili failure örneğini aynı symptom’u koruyarak
en küçük açıklanabilir hâle getirin.

Her azaltma adımında:

- çıkarılan parça,
- beklenen failure ölçütü,
- gözlenen sonuç,
- parçayı dışarıda bırakma veya geri koyma kararı

kaydedilmelidir. Son örnek için üç hipotez ve kontrollü deney üretin. Değişikliği
uygulamadan root cause cümlesini yazın; ardından komşu davranışları doğrulayın.
