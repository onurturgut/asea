# Kaynaklar

- [Chrome DevTools — Breakpoints](https://developer.chrome.com/docs/devtools/javascript/breakpoints): line, conditional ve logpoint davranışları.
- [Chrome DevTools — JavaScript debugging reference](https://developer.chrome.com/docs/devtools/javascript/reference): değişken, scope, call stack ve stepping araçları.
- [MDN — debugger](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/debugger): `debugger` ifadesinin yürütmeyi durdurma davranışı.
- [Git — git bisect](https://git-scm.com/docs/git-bisect): bilinen iyi/kötü sürüm aralığını ikili aramayla daraltma.

Araç belgeleri teknik doğrulama için kullanılmıştır. Chapter, araç ezberinden önce
reproduction, hipotez ve kontrollü deney düşüncesini öğretir.
