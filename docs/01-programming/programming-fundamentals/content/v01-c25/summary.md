# Chapter Özeti

C25’te debugging’i kanıt üreten bir araştırmaya dönüştürdünüz. Failure’ı yeniden
ürettiniz, aynı ölçütü koruyarak minimal case oluşturdunuz, gözlem ve yorumu
ayırdınız. En az üç hipotezi tek değişkenli deneylerle elediniz; breakpoint, log,
scope ve call stack’i belirli sorular için kullandınız. Root cause’u minimal fix
ile giderip failing case ve komşu davranışları doğruladınız. Kanıtlar C26’ya
regression testi olarak devredildi.
