# Bilgi Kartları

- **Search:** Hedefin koleksiyonda bulunup bulunmadığını belirleme.
- **Target:** Aranan değer.
- **Linear search:** Değerleri sırayla inceleyen arama.
- **Binary search:** Sıralı veride olası aralığı küçülten arama.
- **Invariant:** Algoritmanın belirli noktasında doğru kalması gereken ifade.
- **Not found:** Geçerli konum bulunmadı; bu sözleşmede `-1`.
- **Inclusive range:** Her iki sınırın da aralığa dahil olması.
- **Comparator:** İki değerin sıralama ilişkisini belirleyen kural.
