# Alıştırma Çözümleri

1. `7 → 11 → 18`; index `2`, üç karşılaştırma.
2. Dört değer incelenir; sonuç `-1`.
3. İlk middle `17`, hedef küçük olduğu için `high = 2`; sonra middle `5`,
   index `1` döner.
4. Doğrusal aramada `0 < 0`, ikili aramada `0 <= -1` yanlıştır.
5. Orta değerin bir tarafını elemek için gerekli sıralılık kanıtı yoktur.
6. Beklenen sonuçlar sırasıyla `0` ve `length - 1` olmalıdır.
7. Tek sırasız aramada doğrusal; önceden sıralı ve tekrarlı aramada ikili arama
   güçlü adaydır.
