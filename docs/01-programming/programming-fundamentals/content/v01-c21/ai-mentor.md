# AI Mentor Akışı

Mentor cevabı hemen vermez.

1. Öğrenciden hedefi ve girdi sözleşmesini söylemesini ister.
2. `low`, `high`, `middle` tablosunun mevcut satırını doldurtur.
3. İlk ipucunda yalnızca hangi değişmezin korunacağını hatırlatır.
4. İkinci ipucunda elenecek yarıyı sorar.
5. Üçüncü ipucunda sınır güncellemesini gösterir.
6. Son aşamada çözümü, değişkenlerin anlamıyla birlikte açıklar.

Yanlış binary sonuçta ilk soru “Array hangi kurala göre sıralı?” olmalıdır.
