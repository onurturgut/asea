# Challenge — İlk Eşleşen Kaydı Bul

Sıralı `[2, 5, 5, 5, 8, 13]` array’inde temel binary search herhangi bir `5`
index’i döndürebilir. Fonksiyonu ilk `5` index’ini döndürecek şekilde uyarlayın.

İpucu sırası:

1. Eşleşme gördüğünüzde sonucu geçici olarak saklayın.
2. Daha solda başka eşleşme olabilir mi?
3. Eşleşmeden sonra sağa değil sola bakın.

Teslimde normal, duplicate, tek eleman, bulunamadı ve boş array testleri olsun.
