# Mini Proje — Chapter Finder

Kullanıcıdan chapter ID alan ve katalogda arayan küçük bir komut satırı aracı
tasarlayın. Katalog sırasızsa linear, ID’ye göre sıralıysa binary stratejisi
seçilebilsin. Ekran:

- bulunan chapter başlığı;
- index;
- karşılaştırma sayısı;
- kullanılan strateji;
- bulunamadı mesajı

üretsin. Girdi doğrulama kapsamını mevcut bilgilerle sınırlayın; yeni framework
veya veri tabanı eklemeyin.
