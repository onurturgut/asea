# Görselleştirme Notları

1. Linear search için kartların soldan sağa tek tek aydınlandığı animasyon.
2. Binary search için `low`, `middle`, `high` işaretli sayı şeridi.
3. Elenen yarının soluklaşması; hedefin olası aralıkta kalması.
4. Unsorted örnekte yanlış elenen hedefi kırmızıyla gösteren karşı örnek.
5. Hareket azaltma tercihinde animasyon yerine adım tablosu.

Renk tek başına anlam taşımamalı; “incelendi”, “elendi” ve “bulundu” etiketleri
bulunmalıdır.
