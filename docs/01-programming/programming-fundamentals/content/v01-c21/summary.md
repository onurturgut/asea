# Kısa Özet

Doğrusal arama sırasız veriyi baştan sona inceler. İkili arama yalnızca aynı
karşılaştırma kuralına göre sıralı veride aralığın yarısını eleyebilir.
`low..high` hedefin bulunabileceği kapsayıcı aralıktır. Sonuç `-1` ise hedef
yoktur. Strateji; veri sözleşmesi, arama sıklığı ve değişim maliyetiyle seçilir.
