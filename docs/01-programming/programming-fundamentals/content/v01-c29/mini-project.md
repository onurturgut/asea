# Mini Proje Bağlantısı

C29 ayrı bir Mini Project başlatmaz; `V01-P07 — JavaScript Data Reliability
Integrator` projesinin ilk type-semantics artışını üretir.

Öğrenci proje girdilerini raw source/type, accepted grammar, canonical domain type,
conversion, invariant ve failure policy sütunlarıyla kaydeder. C30–C35 bu güvenilir
değerleri object, collection, callback, closure, numeric ve temporal kararlarda
kullanacaktır.
