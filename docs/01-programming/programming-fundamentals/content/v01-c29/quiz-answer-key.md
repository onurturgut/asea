# Quiz Cevap Anahtarı

1. Binding çalışma zamanında farklı type'ta value'lara bağlanabilir; type value'nun niteliğidir.
2. Operator ve abstract conversion kuralları belirlenmiştir; karar runtime value/type ile verilir.
3. Tarihsel `typeof` davranışıdır; Null specification'da ayrı type'tır.
4. Number type'ındadır; `Number.isNaN` ile kontrol edilir.
5. Generic conversion rule domain'in empty, ambiguity ve loss kararını bilmez.
6. `+` string concatenation seçebilir; `-` numeric conversion ister.
7. Boş olmayan bütün string'ler truthy'dir.
8. `===` farklı type'ı dönüştürmez; `==` belirli coercion adımları uygulayabilir.
9. Empty ile gerçek zero birbirine karışabilir.
10. Prefix çıkarmak isteniyorsa doğru; tüm token integer olmalıysa yanlıştır.
11. Önce grammar/shape, sonra converted type/range/invariant.
12. Arithmetic anlamı yoktur ve baştaki sıfırlar/exact text korunmalıdır.
