# Bilgi Kartları

- **Value:** Programın taşıdığı somut değer.
- **Type:** Değer için geçerli operasyon ve semantiği belirleyen kategori.
- **Binding:** Bir adı o anda bir değere bağlayan ilişki.
- **Dynamic typing:** Type kararlarının runtime value üzerinden verilmesi.
- **Explicit conversion:** Geliştiricinin görünür biçimde istediği dönüşüm.
- **Implicit coercion:** Operator veya bağlamın başlattığı örtük dönüşüm.
- **Truthy:** Boolean context'te true'ya dönüşen değer.
- **Falsy:** Boolean context'te false'a dönüşen sınırlı değer kümesi.
- **NaN:** Number type'ında geçerli numeric sonuç bulunamadığını gösteren değer.
- **Strict equality:** Farklı type'ları dönüştürmeden karşılaştırma.
- **Loose equality:** Belirlenmiş type-conversion adımları uygulayabilen eşitlik.
- **Input grammar:** Ham girdinin kabul edilen metinsel biçimi.
- **Canonical type:** Domain içinde tek ve kararlı temsil type'ı.
- **Information loss:** Dönüşümde source bilgisinin geri döndürülemez kaybı.
- **Conversion boundary:** Raw verinin doğrulanıp domain değerine çevrildiği sınır.
