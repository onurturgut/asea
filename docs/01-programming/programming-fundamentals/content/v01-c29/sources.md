# Kaynaklar

- [ECMAScript Language Types](https://tc39.es/ecma262/multipage/ecmascript-data-types-and-values.html#sec-ecmascript-language-types): primitive/object type sınırı.
- [ECMAScript Type Conversion](https://tc39.es/ecma262/multipage/abstract-operations.html#sec-type-conversion): `ToPrimitive`, `ToBoolean`, `ToNumber` ve `ToString`.
- [ECMAScript ToBoolean](https://tc39.es/ecma262/multipage/abstract-operations.html#sec-toboolean): falsy ve truthy dönüşüm davranışı.
- [ECMAScript IsLooselyEqual](https://tc39.es/ecma262/multipage/abstract-operations.html#sec-islooselyequal): `==` coercion adımları.
- [ECMAScript IsStrictlyEqual](https://tc39.es/ecma262/multipage/abstract-operations.html#sec-isstrictlyequal): `===` type-sensitive karşılaştırma.
- [ASEA Teaching Standard](../../../../standards/teaching-and-continuity-standard-v1.md): öğretim ve devamlılık sözleşmesi.
