# P07 Proje Artışı

`V01-P07` için:

- bütün dış input alanlarını ve gerçek runtime type'larını listeleyin,
- her alan için accepted grammar ve absence policy yazın,
- conversion'ı tek boundary fonksiyonunda uygulayın,
- domain içinde canonical type kullanın,
- empty, whitespace, malformed, ambiguous ve lossy testleri ekleyin,
- equality kararlarını strict comparison ile görünür yapın,
- raw → domain trace ve rejected alternative kaydı oluşturun.

C30'a doğrulanmış ve type kararı açıklanmış veri devredilir.
