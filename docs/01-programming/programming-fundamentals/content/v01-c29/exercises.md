# Alıştırmalar

1. `"7" + 2 + 1` ve `"7" + (2 + 1)` için value/type izi çıkarın.
2. `"7" - 2`, `"7px" - 2` ve `Number.isNaN` sonucunu açıklayın.
3. Temel falsy değerleri yazıp `"false"`, `"0"` ve `" "` ile karşılaştırın.
4. `"5" === 5`, `"5" == 5`, `0 == false` adımlarını izleyin.
5. `Number("")` neden teknik olarak 0, domain açısından riskli olabilir?
6. `Number` ve `Number.parseInt` için iki farklı geçerli kullanım contract'ı yazın.
7. Bir öğrenci ID'sinin neden number yerine string olabileceğini savunun.
8. Integer ve boolean raw input için 12 vakalık test tablosu üretin.
