# ASEA Dokümantasyon Sitesi

Next.js, Nextra, TypeScript ve Tailwind CSS tabanlı ASEA dokümantasyon uygulaması.

## Komutlar

- `npm run dev`: geliştirme sunucusunu başlatır.
- `npm run build`: üretim derlemesini ve arama indeksini oluşturur.
- `npm run start`: üretim sunucusunu başlatır.
- `npm run lint`: kod kalitesi kontrolünü çalıştırır.
- `npm run typecheck`: TypeScript tür kontrolünü çalıştırır.

Dokümantasyon sayfaları `src/content` altında MDX biçiminde yönetilir.
