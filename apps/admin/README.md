# ASEA Öğrenci Uygulaması

Lovable ile oluşturulan öğrenci çalışma deneyiminin ASEA monoreposuna
uyarlanmış Next.js uygulamasıdır.

## Development

```sh
pnpm --filter @asea/admin dev
```

Uygulama `http://localhost:3001` adresinde çalışır.

## Built with

- Next.js App Router
- TypeScript
- React
- Tailwind CSS
